Worked examples

What you write, and what you get back

Linear equation

5x + 3 = 2x + 18

  1. Subtract 2x from both sides: 3x + 3 = 18
  2. Subtract 3: 3x = 15
  3. Divide by 3: x = 5

Check: 5(5) + 3 = 28 and 2(5) + 18 = 28 ✓

Simultaneous equations

x + y = 10 and x − y = 4

  1. Add the equations: 2x = 14, so x = 7
  2. Substitute: 7 + y = 10, so y = 3
Quadratic by factorising

x² − 5x + 6 = 0

  1. Find two numbers that multiply to 6 and add to −5: −2 and −3
  2. (x − 2)(x − 3) = 0
  3. x = 2 or x = 3
Identity

(a + b)² = → a² + 2ab + b², with a note that (a + b)² is not a² + b², one of the most common algebra mistakes.

The algebra mistakes students make most

Most wrong answers in algebra come from a handful of slips. Knowing them makes checking much faster:

MistakeWrongRight
Expanding only the first term3(x + 4) = 3x + 43x + 12
Minus sign before brackets10 − (x + 2) = 10 − x + 28 − x
Squaring a sum(x + 3)² = x² + 9x² + 6x + 9
Cancelling across addition(x + 6) ÷ 3 = x + 2x/3 + 2
Losing a solutionx² = 16 → x = 4x = 4 or x = −4

Check my work spots these in your handwritten working and explains the rule behind each one.

How to use Chalkmind for algebra homework

  1. Try it first. Write the question and your working, one step per line.
  2. Stuck? Circle the question and ask for a hint, which gives you the next step only.
  3. Finished? Select your working and tap Check my work.
  4. Still unsure? Ask for the full steps and compare them with yours line by line.
  5. Practise. Ask for practice questions like the one you just solved, getting harder.

Quadratics three ways

For x² + 4x − 5 = 0:

  • Factorising: (x + 5)(x − 1) = 0, so x = −5 or x = 1.
  • Quadratic formula: x = (−4 ± √(16 + 20)) ÷ 2 = (−4 ± 6) ÷ 2, giving 1 or −5.
  • Completing the square: (x + 2)² − 9 = 0, so x + 2 = ±3.

Asking for a different method is a good way to check an answer, and to see which method suits a question best. Plot y = x² + 4x − 5 next to the working to see the roots where the curve crosses the x-axis.

Questions

Can it solve simultaneous equations?

Yes. Write both equations one under the other and select them together.

Does it show the steps?

Yes. Tap Steps to put the working on the board, line by line, under your problem.

Can it plot graphs?

Yes. Write an equation like y = 2x + 1 and plot it as a graph you can pan and zoom, next to your working.

What if I want to try it myself first?

Ask for a hint, or write your own solution and use Check my work to find the first mistake.

Can it handle inequalities and rearranging formulas?

Yes. Write the inequality or formula as you would on paper, for example “make r the subject of A = πr²”, and ask for the steps.
