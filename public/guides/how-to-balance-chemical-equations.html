How to balance chemical equations, step by step

A five-step method that works for almost every equation you'll meet at school, with worked examples from easy to tricky, and a fallback method for when inspection gets stuck.

4 min read · Updated 17 November 2026

A chemical equation is balanced when every type of atom appears the same number of times on both sides. That's the law of conservation of mass in action: atoms are rearranged in a reaction, never created or destroyed.

You balance an equation by changing the coefficients (the big numbers in front of each formula), never the subscripts (the small numbers inside a formula). Changing a subscript changes what the substance is.

The five-step inspection method

  1. Write the unbalanced equation with the correct formulas.
  2. Count the atoms of each element on both sides. A small table helps.
  3. Balance one element at a time, starting with one that appears in only one substance on each side. Leave H and O until last.
  4. Recount after every change, because one coefficient affects every atom in that formula.
  5. Tidy up: make sure the coefficients are the smallest whole numbers possible.

Example 1: making water

H₂ + O₂ → H₂O

Worked
  1. Count: H is 2 on the left and 2 on the right; O is 2 on the left but 1 on the right.
  2. Fix O: put a 2 in front of H₂O: H₂ + O₂ → 2H₂O. Now O is 2 = 2, but H is 2 on the left and 4 on the right.
  3. Fix H: put a 2 in front of H₂: 2H₂ + O₂ → 2H₂O.
  4. Recount: H 4 = 4, O 2 = 2. Balanced.

Example 2: burning methane

CH₄ + O₂ → CO₂ + H₂O

Worked
  1. Carbon first: 1 on each side, already balanced.
  2. Hydrogen next: 4 on the left, 2 on the right. Put a 2 in front of H₂O: CH₄ + O₂ → CO₂ + 2H₂O.
  3. Oxygen last: the right now has 2 (in CO₂) + 2 (in 2H₂O) = 4. The left has 2, so put a 2 in front of O₂.
  4. Result: CH₄ + 2O₂ → CO₂ + 2H₂O. Check: C 1 = 1, H 4 = 4, O 4 = 4.

This pattern (carbon, then hydrogen, then oxygen) works for the combustion of any hydrocarbon. Try propane: C₃H₈ + O₂ → CO₂ + H₂O balances to C₃H₈ + 5O₂ → 3CO₂ + 4H₂O.

Example 3: rusting iron (odd numbers)

Fe + O₂ → Fe₂O₃

Worked
  1. Oxygen is the awkward one: 2 on the left, 3 on the right. The lowest common multiple of 2 and 3 is 6.
  2. Make 6 oxygen atoms on each side: 3O₂ on the left and 2Fe₂O₃ on the right.
  3. Now there are 4 Fe on the right, so put 4 in front of Fe.
  4. Result: 4Fe + 3O₂ → 2Fe₂O₃. Check: Fe 4 = 4, O 6 = 6.

Tip: when one side has an odd number of an atom and the other has a pair (like O₂), use the lowest common multiple, or temporarily use a fraction (2Fe + 1½O₂ → Fe₂O₃) and then double everything.

Example 4: a metal with an acid

Al + HCl → AlCl₃ + H₂

Worked
  1. Chlorine: 1 on the left, 3 on the right. Put 3 in front of HCl.
  2. Hydrogen is now 3 on the left and 2 on the right. The lowest common multiple is 6: use 6HCl and 3H₂.
  3. Chlorine is now 6 on the left, so use 2AlCl₃, which needs 2Al.
  4. Result: 2Al + 6HCl → 2AlCl₃ + 3H₂. Check: Al 2 = 2, H 6 = 6, Cl 6 = 6.

Example 5: polyatomic ions as one unit

When a group like sulfate (SO₄), nitrate (NO₃) or phosphate (PO₄) appears unchanged on both sides, balance it as a single unit. It's much faster than counting its atoms separately.

Ca(OH)₂ + H₃PO₄ → Ca₃(PO₄)₂ + H₂O

Worked
  1. Calcium: 1 on the left, 3 on the right. Use 3Ca(OH)₂.
  2. Phosphate (PO₄) as a unit: 1 on the left, 2 on the right. Use 2H₃PO₄.
  3. Hydrogen on the left: 3 × 2 (from OH) + 2 × 3 (from H₃PO₄) = 12, so you need 6H₂O on the right.
  4. Result: 3Ca(OH)₂ + 2H₃PO₄ → Ca₃(PO₄)₂ + 6H₂O. Check: Ca 3 = 3, PO₄ 2 = 2, H 12 = 12, O (outside PO₄) 6 = 6.

When inspection gets stuck: the algebraic method

For complicated equations, give each coefficient a letter and write one equation per element.

Worked

a Fe + b O₂ → c Fe₂O₃

  • Iron: a = 2c
  • Oxygen: 2b = 3c

Choose c = 2 (the smallest value that makes everything whole): then a = 4 and b = 3, giving 4Fe + 3O₂ → 2Fe₂O₃, the same answer as Example 3.

Common mistakes

MistakeWhy it's wrong
Changing a subscript, e.g. H₂O → H₂O₂It turns water into hydrogen peroxide: a different reaction.
Forgetting a coefficient multiplies the whole formula2H₂O has 4 H and 2 O, not 4 H and 1 O.
Not recounting after a changeFixing one element often unbalances another.
Leaving coefficients that share a factor4H₂ + 2O₂ → 4H₂O should be simplified to 2H₂ + O₂ → 2H₂O.

Practice questions

  1. N₂ + H₂ → NH₃
  2. Mg + O₂ → MgO
  3. C₂H₆ + O₂ → CO₂ + H₂O
  4. NaOH + H₂SO₄ → Na₂SO₄ + H₂O
Answers
  1. N₂ + 3H₂ → 2NH₃
  2. 2Mg + O₂ → 2MgO
  3. 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O
  4. 2NaOH + H₂SO₄ → Na₂SO₄ + 2H₂O

Questions

Why do chemical equations need to be balanced?

Atoms are not created or destroyed in a chemical reaction (conservation of mass), so the number of each type of atom must be the same on both sides.

Can I change the small numbers (subscripts) to balance an equation?

No. Changing a subscript changes the substance itself, for example H₂O (water) into H₂O₂ (hydrogen peroxide). Only change the large numbers in front (coefficients).

Which element should I balance first?

Start with an element that appears in only one substance on each side, usually a metal or carbon. Leave hydrogen and oxygen until last, because they often appear in several substances.

What if I end up with a fraction?

That's allowed as a working step. Multiply every coefficient by the denominator at the end so all coefficients are whole numbers.
